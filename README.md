# F-16C VIPER · TACTICAL SIM

单色磷光绿 CRT 风格的 **F-16C Block 50 战斗机座舱 UI + 基础数值仿真** 网页。
参考《战争雷霆》的数据密集驾驶舱呈现方式，纯前端、无构建步骤、无外部依赖。

> 本项目只做 **UI 系统 + 数值计算系统**（不含 3D 视图），用于展示飞行力学、雷达探测、
> 导弹弹道、反跟踪对抗与姿态控制之间的耦合关系。
> 所有参数取自公开资料，气动/发动机为工程近似模型，**不用于训练或任何实际用途**。

### 座舱面板（`J`）· 四边露出 + 视角转动

五块面板重叠在同一个视口里，靠 `transform` 决定谁在正面：

* 非当前面板整体移出视口，**只留 34 px（窄屏 26 px）的边缘**在四边
* 当前面板 `inset: peek`，四周留出一条缝，露出邻居的边缘条
* 点边缘条 / 滑动画布 → 面板滑入正面，原来的面板退到 `translateZ(-160px) scale(.96)`
* 「全览」模式把五块面摊回 CSS grid（桌面宽屏一次看全）

边缘条显示的是真内容：上边 = `257.800 · TOWER`，左边 = `RPM 66% · FUEL 3160 KG`，
右边 = `GEAR DN · SB 0%`，下边 = 当前检查单。面板本身由 `js/data/cockpit.js`
的数据描述生成（`sel / tog / btn / ro / bar / freq / preset / atc`）。

### 冷舱起动流程

```
MAIN PWR → BATT
FLCS PWR TEST（按住 1.4 s）
MAIN PWR → MAIN PWR
FUEL MASTER → MASTER
JFS → START            ≈4 s 后 JFS RUN（RPM 20%）
油门 → IDLE（> 18%）    点火，FTIT 峰值 ~650 °C
                       约 18 s 到达慢车 RPM 65%
HYD A/B 建压 2850–3250 psi
```

引擎的转速由 `Systems` 接管并直接喂给 `Turbofan.update(forcedSpool)`，
所以起动过程中的推力、油耗、喷口、FTIT 都是真实耦合的。

### 地面与起降物理

* **抬轮**：杆量 → 俯仰姿态（≈7°/s），`升力 > 重量 × 1.02` 且已抬轮且 `V > 52 m/s` 才离地
* **前轮转向**：`ω = V·tan(δ)/轴距`，δ 为杆量^1.7 × 35°，角速度上限 20°/s，70 节自动断开改方向舵
* **刹车**：`F = μ_brake·N`，`N = W − L`，防滑关闭时效率降到 72%
* **接地**：下沉率 > 1000 fpm、坡度 > 15°、未放起落架 → 损毁；> 620 fpm → 弹跳
* **道面**：跑道 μ=0.018 / 滑行道 0.022 / 草地 0.075

### 导航计算

**TACAN**（126 波道 X/Y，机载 1025–1150 MHz，地面 962–1024 / 1151–1213 MHz）

```
方位 = bearing(本机 → 台站)
径向 = 方位 + 180
DME  = √(水平距离² + 高度差²)      ← 斜距，不是地面距离
CDI  = (选定航道 − 参考方位) / 2    ← 全刻度 ±10°
```

**ILS**

```
航向台偏差 = atan2(横向偏移, 沿跑道距离)      全刻度 ±2.5°，1 dot = 0.5°
下滑台偏差 = atan2(高度差, 水平距离) − 3.0°   全刻度 ±0.7°，1 dot = 0.14°
有效范围   ：沿跑道方向 0–34 km、扇区 ±35°
```

HUD 着陆模式：AOA 括号（顶边 = 11°，进近基准）、航向道/下滑道偏差杆、
雷达高度表、`GEAR DN` / `SPD BRK` 状态；ADI 同步显示 ILS 十字。

### 起降全流程（默认关卡）

```
跑道 09 对正 → 塔台 257.800 请求起飞（\ 或无线电条「发话」）
  ↓ 70 节断 NWS · 140 节抬轮 10° · 离地收起落架
前出 CAP BRAVO → 交战 → 击落全部敌机
  ↓ 自动进入返场阶段（任务目标变成 RTB）
TACAN 96X / ILS 110.30 → 放起落架 + 减速板 → 11° 迎角
  ↓ 接地（下沉率 < 600 fpm）→ 刹车 → 停住
任务成功（战果页记录起飞 / 着陆 / 接地下沉率）
```

> 只击落敌机不落地 = 任务未完成，塔台会提示重新起飞。
> 「空中开始」模式仍然保留（设置里的起始方式），用于快速空战练习。

### 无线电（KVPX）

* 底部无线电条常驻：`COM1 257.800 TOWER` + 预置 `TWR/GND/APP/CLR/DEP/ATIS` + 「发话」
* `[` / `]` 以 25 kHz 步进调频；`\` 按当前阶段自动选择最该说的一句

## 部署（Cloudflare Pages）

站点是**纯静态**的，无需打包器；`tools/build-pages.sh` 只是把要托管的东西收进 `dist/`
（`index.html` + `css/` + `js/` + `_headers`），测试脚本与文档不会上线。

### 方式一：Git 集成（推荐，push 即部署）

1. Cloudflare Dashboard → **Workers & Pages** → **Create** → **Pages** → **Connect to Git**
2. 授权 GitHub，选中本仓库，分支 `main`
3. 构建配置：
   * Framework preset：**None**
   * Build command：`sh tools/build-pages.sh`
   * Build output directory：`dist`
   * 环境变量：无（不需要 Node 版本以外的任何东西）
4. **Save and Deploy** → 得到 `https://f16-sim.pages.dev`

之后每次 `git push` 到 `main` 会自动重新部署，PR 还会生成预览域名。

### 方式二：命令行直传（本地已登录 wrangler 时）

```bash
sh tools/build-pages.sh
npx wrangler pages deploy dist --project-name f16-sim
```

### 缓存说明

`js/` 里的模块之间用**无版本号的 ES module 互相 import**，所以 `_headers` 刻意只用
`max-age=600` 而不是长期 immutable 缓存，避免更新后 HTML 引用到旧模块。

## 数值系统

### 1. 标准大气（`js/core/atmosphere.js`）

ISO 2533 分层模型 0–32 km（对流层 −6.5 K/km、11–20 km 等温、20–32 km +1 K/km），
输出 `T / p / ρ / a / σ / δ / θ`，用于推力衰减、升力/阻力、马赫数、雷达地平线。

雷达（视觉）地平线：`R = 4120·(√h₁ + √h₂)` 米。

### 1.5 FLCS 飞行控制律（`js/sim/fcs.js`）

```
杆量整形      shape(v) = sign(v)·(0.34|v| + 0.66|v|^1.75)     ← 中心区细腻，满杆仍是 1
俯仰          nCmd = 1 + pitchIn·(nMax−1)                     空中：G 指令
              nCap = min(nLift, nAlpha, nStruct)              α/G/结构三重限幅
迎角限制器    αLimit = aoaBase − (aoaBase−16°)·(|nCmd|−1)/8     25°@1G → 15°@9G
CAT III       起落架放下：αLimit ≤ 20°，G ≤ 5.5，滚转权限 ×0.7
滚转          pCmd = rollIn·260°/s·f(α)·f(q)·auth
偏航          rCmd = rudder·16°/s + χ̇·0.9（转弯协调 / 偏航阻尼）
配平          trimPitch ±0.22 杆量等效偏置
液压失效      auth 0.45（手动回传）
G-LOC         8.2 G 持续 2.2 s 起算，最多损失 70% 操纵权限
```

### 1.6 风场与地面效应（`js/sim/wind.js`）

```
风切变   V(h) = V0·((h+10)/10)^0.16       地面 4 m/s → 3000 m ≈ 1.8×
阵风     g(t) = Σ sin(ωᵢt+φᵢ)             低空边界层增益 ×(1+1.4e^(−AGL/260))
地速     Vgs = |V·(cosγ·sinχ, cosγ·cosχ, sinγ) + W|
扰动     Δα = 2.2·w_z（有界 ±3.5°），Δβ = f(gust)
地面效应 ge = 1 − 0.42·max(0, 1−AGL/9.96)  贴地诱导阻力 −42%
```

菜单/无线电台风数据与 HUD 左下 `W 090/06`、座舱「飞控状态」里的 β / 权限 / 风向都取自这里。

### 2. 发动机 F110-GE-129（`js/sim/engine.js`）

```
δ      = p / p₀
ram    = 1 + (0.12 + k·(1−δ))·M        k = 0.50 (军推) / 0.90 (加力)
T_mil  = 76.3 kN · δ^0.86 · ram_mil
T_ab   = 131 kN  · δ^0.95 · ram_ab
包线限制: machFactor = clamp((2.18 − M)/0.30, 0, 1)
          qPenalty   = clamp(1 − (q−66 kPa)/60 kPa, 0.25, 1)
T = [T_mil·(idle + (1−idle)·spool) + (T_ab − T_mil)·abLevel] · machFactor · qPenalty
```

* 燃油流量按军推/加力分别使用 TSFC = 2.12e−5 / 4.80e−5 kg·N⁻¹·s⁻¹
* 结果：海平面极速 ≈ **M 1.20（≈777 KEAS）**，11 km 极速 ≈ **M 2.06**
* 转速、EGT、喷口开度均有独立一阶滞后，用于仪表动画

### 3. 飞行力学 + FLCS（`js/sim/flight.js`）

点质量 3-DOF + 滚转通道：

```
V̇   = (T·cosα − D)/m − g·sinγ
γ̇   = (g/V)·(n·cosφ − cosγ)
χ̇   = (g/(V·cosγ))·n·sinφ
φ̇   = p           (滚转角速度指令，随 α 与 q 降级)
```

FLCS 限幅链（参照 Falcon BMS 公开的 FLCS 开发笔记）：

1. 杆量 → 法向过载指令 `nCmd ∈ [−3, +9]`
2. **迎角限制器**：α 上限随 G 从 25°（1 G）收紧至 15°（9 G）
3. **升力限制**：`nAvail = q·S·CLmax / W`
4. G 变化率限制 6.5 G/s + 一阶滞后
5. 滚转权限随 α、q 降级

气动：`CL = CLα·α`（CLα = 0.0955/°，CLmax = 1.72），
`CD = CD0 + K·CL² + CD_wave(M) + 减速板/起落架`，`K = 1/(π·AR·e)`（AR=3.56, e=0.78）。
跨音速波阻隆起 `CD_wave = 0.034·exp(−((M−1.02)/0.29)²)`。

### 4. 火控雷达 AN/APG-68(V)5（`js/sim/radar.js`）

雷达方程的四次方根缩放：

```
R_max = R_ref · (σ/σ_ref)^(1/4) · (1+J)^(−1/4) · RCS_姿态因子
Pd    = 1 / (1 + (R/R_max)^4)
```

* `R_ref = 80 km @ 5 m²`，方位扫描 ±10 / ±30 / ±60°，1/2/4 条扫描线，扫描周期 4 s
* **多普勒凹口**：下视且目标径向速度 |Vr| < 38 m/s 时探测概率 ×0.06
* **地形遮蔽**：目标低于雷达地平线则不可见
* **低空杂波**：下视近距额外衰减
* 干扰：`R_max × (1 + 1.8·J)^(−0.25)`，己方 ECM 开启时自扰 ×0.86
* 航迹质量随照射累积、随未照射衰减，STT 锁定在质量 < 0.22 持续 1.6 s 后中断

RWS / TWS / STT 三模式，B 型（方位 × 距离）显示器含余晖、扫描线、包线弧与锁定框。

### 5. 导弹（`js/sim/missile.js`）

| 型号 | 制导 | 质量 | 最大过载 | 参考射程 |
| --- | --- | --- | --- | --- |
| AIM-120C-5 | 主动雷达 (ARH) | 152 kg | 40 G | 105 km |
| AIM-9M | 红外 (IR) | 85.5 kg | 30 G | 20 km |
| R-77 | 主动雷达 | 175 kg | 35 G | 90 km |
| R-73 | 红外 | 105 kg | 40 G | 22 km |

三维比例导引：

```
ω = (R × V_rel) / |R|²
a_cmd = N · V_c · (ω × R̂)      N = 3.2–3.8
```

* 加速度投影到垂直于速度矢量的方向（只转向、不做功），按 `maxG` 限幅
* 弹道含变质量、跨音速波阻、重力
* ARH：中段数据链预测拦截点 → 进入 `seekerRange` 开机（pitbull）→ 凹口判定
* IR：迎头/尾后锁定距离不同 + 视场角判定 + 曳光弹诱骗
* **扫掠线段近炸判定**，避免高速穿透漏检
* 杀伤概率 Pk 由距离/过载规避/高度/发射质量/对抗措施联合给出

### 6. 反跟踪系统（`js/sim/countermeasures.js`）

* **AN/ALR-69(V) RWR**：可探测距离 = 对方雷达距离 × 1.45，输出方位、型号码、波段、威胁等级
  （Search → Acq → Track → **Launch** → Lethal），带 1.5 s 余辉与发射告警音
* **AN/ALQ-184(V)9 ECM**：NOISE / DECEPTION 两档，降低对方探测距离但暴露自身（支持反辐射）
* **AN/ALE-47 CMDS**：60 箔条 + 60 曳光，P1 单发 / P2 双发曳光 / P3 箔条×2 / P4 混合，
  带 0.55 s 冷却与多连发时序
* **战术提示**：根据来袭导弹类型给出 NOTCH / BEAM / 收油门等规避建议
* 诱饵为独立实体（有速度、阻力、寿命、RCS/红外特征），可被导引头"抢走"

### 6.5 预警机 / 战术数据链（`world.js` · `radarScope.js`）

* `MAGIC 01`（E-3 量级）在 260 km 外盘旋，每 2 s 推送一次监视航迹
* 航迹经过「距离 + 雷达地平线」双重筛选后进入 `world.datalink`
* **不依赖本机雷达辐射**：即使关掉雷达或目标超出 APG-68 探测距离，态势仍然可见
* 雷达显示器上以**青色虚线方框 + `DL`** 绘制，并标注高度差箭头；
  超出方位扫描扇区的航迹被钳到边缘，与实心菱形（本机雷达探测）明确区分

### 7. 姿态控制系统（`js/sim/autopilot.js`）

## 战场态势图（游戏 UI）

不是机载航电，而是给玩家的「战场感知」界面，两层：

**1. 常驻小地图**（控制台内，100×100）

* 本机始终居中，机头向上（可切正北）
* 敌方（琥珀）/ 友军预警机（青）/ 导弹（红）/ 航路点 / 防空威胁环
* 超出范围的接触被钳到边缘，不丢失方位
* 点击 `MAP` 打开全屏图

**2. 全屏 2.5D 战场图**（`M`）

使用**真正的针孔相机透视投影**，不是简单的斜切：

```
相机位置 = 地图中心 − 前向·D + 上·H        H = D·tan(35°)
视线方向 d = (前向·D − 上·H) / |…|
右向量 R = (cos χ, −sin χ, 0)
上向量 up = R × d
屏幕坐标 = (cx + f·(v·R)/(v·d),  cy − f·(v·up)/(v·d))
```

因此：远处目标会向地平线收敛、高空目标会"浮"在其地面投影之上、被地面网格正确地
随距离压缩 —— 这就是"接近 3D"的来源。

画面元素：

* 地平线 + 天空/地面渐变 + 距离雾衰减的地面网格（5/10/20 km 自适应）
* 每架飞机有一条**高度杆**连到地面投影点，杆长即高度
* 敌方（琥珀箭头，指向其航向）/ 友军预警机（青色圆）/ 来袭导弹（红色三角）
* 防空阵地 75 km 威胁环、本机 20/40/60 km 距离环
* 航路点菱形 + 虚线航线，当前航路点高亮
* 本机：脉冲光环 + `YOU` 引线 + 高度/空速读数
* 右侧接触列表（方位 / 距离）与本机状态（坐标、航向、高度、空速、当前航路点）
* 底部示意：拖动旋转、滚轮缩放、右键复位

**接触可见性规则**（这是"感知"而非"作弊"）：

| source | 条件 |
| --- | --- |
| `radar` | 本机雷达已建立航迹 |
| `datalink` | 预警机 MAGIC 01 的监视航迹（不需要本机雷达辐射） |
| `intel` | 任务简报里的固定阵地（防空） |
| `rookie` | 菜鸟模式：无条件显示全部敌机 |

图标样式也随之区分：实线 = 雷达，虚线 = 数据链，点线 = 菜鸟，点划 = 情报。

## 菜鸟模式

* `K` 键或顶栏「新手」按钮即时切换（无需重开任务）
* 效果：`world.rookie = true` → 战场态势图、雷达显示器、小地图全部显示敌机
* 同时启用**情境提示**：屏幕下方按优先级给出 1–2 条可执行提示，例如
  `[T] 锁定 FLANKER 1-1（52 km）`、`[Space] 目标在发射包线内 — 可以发射`、
  `[C / F] 投放干扰弹 → 与威胁成 90° 置尾`
* 提示优先级：导弹告警 > 失速 > 迎角临界 > 燃油 > 发射包线 > 锁定建议
* 在 `设置 → 菜鸟模式 / 情境提示` 可分别关闭

## 新手教程

主菜单「新手教程」→ 选择课程 → 开始。课程按真实训练大纲顺序编排：

| # | 课程 | 步数 | 教什么 |
| --- | --- | --- | --- |
| 01 | 基础飞行 CONTACT FLIGHT | 6 | 油门 / 加力 / 平飞 / 滚转改平 / 爬升 |
| 02 | 能量与过载 ENERGY & G | 5 | 5G、9G 限幅、迎角限制器、能量补充、超音速 |
| 03 | 雷达与锁定 RADAR & LOCK | 5 | 量程、扫描、发现、STT、模式切换 |
| 04 | 超视距交战 BVR | 4 | 锁定、发射、Crank 转向、保持接触 |
| 05 | 近距格斗 WVR | 5 | 切弹、把目标放进 HUD、发射、切炮、开火 |
| 06 | 防御与反跟踪 DEFENSIVE | 5 | RWR、箔条、曳光弹、ECM、Notch 置尾 |

**实现方式**

* 每节课是一个 `{ setup(world), steps[] }` 对象；`setup` 直接改写战场（清空敌机、
  摆位、生成靶机、甚至发射一枚来袭导弹）
* 每步是 `{ title, text, hint, key, highlight, hold, timeout, check(world) }`
* `check` 每帧对真实仿真状态求值；`hold` 要求持续满足 N 秒；`timeout` 用于纯讲解步骤
* `highlight` 会把对应控件（油门 / 驾驶杆 / LOCK / FIRE / 雷达画布…）加上脉冲高亮
* 完成状态写入 `localStorage`，课程卡上显示 ✔

**练习场**：`TRAINING` 场景生成两架 `passive` 靶机，沿圆形航线巡航、不还击、
不开火，随便练。教程里的 `damageScale` 会把受到的伤害压到 15%–25%，允许犯错。

## 任务与 AI

| 场景 | 配置 |
| --- | --- |
| `CAP-BRAVO` | 跑道 09 起飞 → Su-27 + MiG-29（52–70 km 南下）→ 返场着陆 |
| `1V1 DUEL` | 单架 MiG-29，36 km 迎头 |
| `BVR ADVANCED` | 双 Su-27，78–82 km 高空高速 |

> 空战场景默认「跑道热机」起始：**必须完成起飞并在战后返场着陆**才算任务成功。
> 玩家还没离地时敌机保持巡逻，不会把停在跑道上的飞机直接打掉。
> 在「任务场景」页可以把起始方式改成「冷舱起动」或「空中开始」。

敌方 AI 状态机：`PATROL → ENGAGE → DEFEND`。
被导弹锁定时切入 90° 置尾（NOTCH）、投放箔条/曳光并按需俯冲加速；
进入发射包线后按武器优先级发射，发射间隔 9–18 s。

战场同时存在 S-300PS 地空雷达阵地，只作为 RWR 辐射源出现。
